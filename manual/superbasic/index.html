SuperBasic vs Other Basics

So what is SuperBasic and why did we need our own manual on it? If we follow the wikipedia rabbit hole we'd find that SuperBasic was an improvement on Basic by the folks at Sinclair. I think the idea was to showcase it as the primary basic for a product called the SuperSpectrum, but it never came to fruition.

It has however, shown up today in the Foenix series of 8-bit computers were it really shines with the extra memory and modern components inside.

Graphics and Text Improvements

Commodore basic was a very limited command set and really required the user to do a lot of peeking and poking (see our chapter on that) to get anything accomplished graphically. Superbasic gives direct access to graphics, sprites, text placement, bitmaps and tilesets without the need for direct memory manipulation, though you certainly could do it that way.
